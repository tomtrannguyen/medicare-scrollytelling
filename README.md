# medicare-scrollytelling

Interactive scrollytelling page analyzing a decade of Medicare spending trends (2014–2024) using CMS Geographic Variation Public Use File data. Built with R, Quarto, and the closeread extension.

## Data Source

CMS Geographic Variation Public Use File (2014–2024)  
https://data.cms.gov/summary-statistics-on-use-and-payments/medicare-geographic-comparisons/medicare-geographic-variation-by-national-state-county
